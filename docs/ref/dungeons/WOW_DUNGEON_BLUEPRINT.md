# WoW dungeon blueprint: how 5-player dungeons are built, mapped onto our data format

Research date: 2026-10-16. Audience: implementer agents that restructure `src/data/dungeons/*.ts`.
Reference implementation of the target shape: `src/data/dungeons/kemik_mahzeni.ts` (15 rooms, 17 doors, 27 packs, 3 bosses, 2 shortcut doors, 1 optional room).

## 0. Reading guide

Tags: **[src]** stated by a source I read (URL in section 9). **[loc]** from the local ref docs in `docs/ref/dungeons/`. **[code]** read from our TS files (stats generated by loading `src/data/dungeons/index.ts`). **[inf]** my inference or general WoW knowledge. ### 0.1 Our units

- `TILE_SIZE = 4` m (`src/types/dungeons.ts`). Continuous tile `c` maps to world `(c + 0.5) * 4`. Room/door rects are tile-corner based; props, packs, bosses use centre coordinates (`kit.ts` COORDINATES note).
- 1 tile = 4 m = about 4.4 yd. WoW melee range is 5 yd, so one tile is roughly one melee range. [inf]
- `DoorDef.width` is in tiles (default 1). Our corridor-ish rooms are 4 tiles wide today (16 m = 17.5 yd), which is wider than most WoW corridors. [code][inf]
- Season dungeons use `timerSec` 1515..1920 s (25..32 min), `forcesRequired` about 80% of the summed pack forces. [code] (kemik 235/295 = 80%, taskasa 400/498 = 80%, buyucu 400/493 = 81%).

### 1.3 Layout archetypes (pick one per dungeon, do not mix more than two)

1. **Linear with a fork that rejoins** (Halls of Valor, Ara-Kara after boss 1, kemik_mahzeni): boss A -> two parallel branches of 2-4 packs each -> merge room -> boss B. In data: one room with 3 doors (`degree 3`), two parallel rooms, a merge room, `cycles >= 1`.
2. **Hub and spokes with return** (Stonevault, Nexus-Point Xenas, Windrunner Spire): entrance hub -> any-order wings, each ending in a boss and a return device -> final gated section. Data: hub room degree 3-4, wing end door `boss_exit` or a `transits` cart/conduit back to the hub, the third door `gate: 'kill_lock'` with `requires` or `opensOn` for both wing bosses (or `event_lock` fed by an event).
3. **Vertical ascent** (Magisters' Terrace, Court of Stars balconies): use `floorY`, `slopes`, `heightAreas`, `lifts`, `tiers` (set `vertical: true`), final boss highest. Each floor change is a pacing beat.
4. **Descent and escape** (Maisara descent, Pit of Saron, Darkflame Cleft's cart): linear, narrow, one-way; ends with a chase or escort set piece. Use `kill_lock` doors that close behind the group for the one-way feeling.

Rules for any archetype:

- **Branch width**: parallel branches are 4-8 tiles wide each (16-32 m), separated by a wall with at least one pinch door so a pack cannot be pulled across both. [inf]
- **Dead end**: exactly 1-2 optional rooms (`optional: true`, packs `optional: true`) holding a buff station, a chest (`extras.chests`) or a mini-boss pack. WoW examples: Magisters' Terrace Arcane Tome, Priory light orbs, Cinderbrew honey pot, Court of Stars side rooms. [src]
- **Shortcut**: exactly 1, closed until a boss kill (`gate: 'kill_lock'`, `opensOn: { boss }`, as `shortcut()` in kemik_mahzeni). WoW examples: Stonevault carts, Windrunner/Xenas conduits, Floodgate glider, Dawnbreaker flight skip. Shortcut doors should be 2 tiles wide (a chokepoint).
- **Gating** (what opens a door):
  - `boss_lock` / `boss_exit`: the standard arena doors; every boss arena has one of each. [code]
  - `kill_lock` + `opensOn.pack` / `requires`: "kill the Pyromancer to open the library" (Magisters' Terrace), "kill the mini-boss to open the sealed exit" (Maisara Rokh'zal), "three Lieutenants" (Priory). Use 1-2 per dungeon.
  - `event_lock` + `DungeonDef.events`: scripted events (Court of Stars spy hunt; yildiz_divani already has it). Use at most 1-2.
  - `device_lock` + `extras`/`devices.ts`: lever, valve, console (Xenas start console opens the bridge; Floodgate stockpiles). Use 0-1.
  - Collect-N gate (Maisara prisoners 8/12, Floodgate 5 stockpiles): emulate with `requires: [packIds]` on a door where each "object" is a small pack/prop group.
- **Entrance set piece** (first 60 s): the first room already shows the theme and one pack with a readable interrupt or CC lesson. WoW: Ara-Kara three mini-bosses visible in the first hall; Dawnbreaker airship take-off; Xenas three factions fighting in the start room; Windrunner spectral groundskeepers. Data: first room `rooms[0]` with 1-2 packs (small) and 6+ props; never an empty `giris` (many of our files have an empty entrance room, see 0.2: giris/empty list).
- **Finale set piece**: the last boss room is the largest or highest room, has the most hand-placed props, a unique zone (`zones`: rune circle, pit, lava, `dais`), a room light colour change, and a short approach corridor (2 wide, 8-12 tiles long) that frames the door. WoW: Stonevault Titan tunnels to a void-rift hall; Rookery three platforms; Dawnbreaker deck; Darkflame Cleft cart chase; Magisters' Terrace orrery.

### 1.4 Branch-order and fork examples worth copying

- Windrunner Spire: after the shared entrance, either wing first; both wings return by conduit to the entrance; the boss after them is behind a new path. [src] -> our `golge_tapinagi` (two parallel bosses at order 1) fits this exactly.

## 2. Space and scale

### 2.1 What is known

No source gave metres. Dungeon pages and loading-screen descriptions agree on scale words: "cavern-scale stone halls" (Stonevault), "long colonnades" and "domed observatory" (Magisters' Terrace), "bridge gauntlet" (Maisara), "three platforms around the boss" (Rookery), "central hole with grates" (Rookery), "balcony swept by wind zones" (Court of Stars). [src][loc] Everything numeric below is [inf], calibrated against our `kemik_mahzeni` rooms and the kind of fights described in Section 4.

### 2.2 Room table (tile units; 1 tile = 4 m)

| room type | width x depth (tiles) | m | purpose / WoW analogue |
|---|---|---|---|
| connector corridor | 2 x 6-14 | 8 m wide | pinch between packs; Stonevault "Final corridor", Court of Stars alleys |
| wide corridor / gallery | 3-4 x 10-20 | 12-16 m | route fork lane, Halls of Valor Ephemeral Way |
| small trash room | 6 x 6 to 9 x 9 | 24-36 m | 1-2 packs, one prop landmark |
| standard trash hall | 10 x 10 to 14 x 12 | 40-56 m | 2-3 packs, patrol loop, 2 exits |
| set-piece hall | 16 x 10 to 24 x 12 | 64-96 m wide | Magisters' Terrace plaza, Court of Stars ballroom, Priory courtyard |
| boss arena (standard) | 12 x 12 to 14 x 14 | 48-56 m | 2-3 telegraphed AoE zones fit with room to run |
| boss arena (large) | 16 x 14 to 20 x 16 | 64-80 m | adds + soak circles + frontals; final boss and fork bosses |
| boss arena (final) | 18 x 14 to 24 x 18 | 72-96 m | finale, platform or multi-level |
| hub | 12 x 12 to 20 x 16 | 48-80 m with 3-4 doors | Stonevault central processing, Xenas start room |

Current arena sizes [code]: kemik 14x14, 14x16, 13x12; kizil/buzul 12x12 each (all 3 bosses identical); golge 12x12, 12x12, 14x14; taskasa 18x13, 14x14, 12x12 (x2), 24x18; buyucu 20x16, 18x14 x3; kefaret 15x14, 24x12, 20x14, 16x12. Good: buyucu, kefaret, taskasa. Weak: kizil, buzul, golge (every boss room is 12x12 = same footprint).

Rules:

1. Boss arenas differ from each other in footprint and in aspect ratio. No two bosses in a dungeon share the same `w x h`. (A 24x12 strip, an 18x18 square, a 13x15 oval-ish ring via `zones` circle.)
2. Boss arena minimum: 12x12 tiles. Add `heightAreas` rim `'rail'` or a pit/lava zone (`zones` with `blocked: true`) only if the remaining walkable floor is at least 100 tiles.
3. Door widths: arena doors (boss_lock / boss_exit) 4 tiles wide; every other connector 2 tiles; only "grand" doors (hub-to-hall) 4-6. Never width 1 for gameplay doors unless it is a deliberate pinch.
4. A room has at most 4 doors. Doors never sit within 2 tiles of a room corner. Opposite doors give a through-route; adjacent doors force a turn (use turns to hide the next pack).
5. Route length between two boss arenas: 25-60 tiles of path (100-240 m), i.e. 20-45 s at a walk. [inf]
6. Landmarks: every room has at least one visible landmark seen from every door (a statue, brazier cluster, large banner, crystal, tree). Boss arenas have 2: one centre feature and one edge feature.
7. Sightlines: from the door, the player sees the room's main landmark and at least half of the pack. No door looks straight into a wall within 2 tiles.
8. Verticality: use at least 3 height levels per dungeon (`floorY`, `heightAreas` y 0/2/4, `slopes` of kind `stairs` or `ramp`). Arenas for the finale are the highest or the lowest room. Galleries (`tiers` kind `gallery`/`balcony`) are decorative, not walkable.
9. Corridors with turns: no straight corridor longer than 10 tiles without a prop change (light colour shift, fallen pillar, banner). Prevents the "tube" feeling.
10. Set-piece rooms get their own `atmosphere` (fog blend; see `DungeonDef.atmospheres`) and `lightColor`.

### 2.3 Layout geometry templates (all in tile corners; shift to dungeon grid)

- **Backbone**: a snake of 4-5 rooms with 2-wide connectors; total path 120-200 tiles. 
- **Fork**: split at a hub; two parallel rooms 8-12 tiles wide; rejoin in a room of 14-20 wide.
- **Cart/conduit link**: a long 2x10 corridor drawn as a decorative rail (`transits`: two stops, 1 per wing), used instead of a door.
- Never lay rooms on a perfect grid with identical sizes (kizil/buzul pattern: giris 5x6, k_giris 4x4, room 10x11, k_ 4x5, boss 12x12). Alternate sizes by at least 30%.

## 3. Trash design

### 3.1 What WoW does (evidence)

- Pack members come in **roles**; Method tags every trash mob: **tank** (stacking melee debuff), **interrupt** (specific cast), **CC-immune / important** (big threat), **healer** (heals others), **frontal**, **purge/dispel**, **hazard-creating** (puddles or death explosion). Example Windrunner Spire: Dutiful Groundskeeper (tank), Restless Steward (interrupt + magic dispel), Spellguard Magus (CC-immune, zone at 50%). [src Method]
- Typical composition seen across Ara-Kara, Windrunner, Xenas, Dawnbreaker, Cinderbrew, Darkflame: 1 tank-type melee + 1-2 casters with an interruptible cast + 1 utility (healer, hazard) per pack, with 1 CC-immune "important" mob in bigger pulls. [src]
- Packs carry **one lesson each**: kick or stand in puddles or kite or pull one at a time ("Hired Muscle... pull only one at a time", "Hulking Bloodguard CC-immune, avoid Impale"). [src]
- **Lieutenant / mini-boss** packs sit at section ends and are CC-immune with interruptible casts (Ara-Kara Ixin/Nakt/Atik; Dawnbreaker three mini-bosses; Maisara Rokh'zal, Zil'jan). [src]
- **Patrols**: Ethereal patrols overlap the Magisters' Terrace hallway and should be pulled late; Pale Priests patrol in City of Threads; Stonevault Despoiler patrols near G11-G14. [src][loc]
- **Linked/bound**: Priory Lieutenants dropping guards from the boss; Cinderbrew "Yes Man + 3 others heal to full when one dies"; Fel Covenant emissaries in Court of Stars. [src][loc]
- Noise reduction: Blizzard states Midnight reduced trash noise, fewer cast bars; spikier hits get longer cast bars. [src seramate]
- Average pack size in older M+ routes: 2.5 (Halls of Valor), 3.3 (Court of Stars). [loc]

### 3.3 Pack sizing and forces (M+)

- In WoW, bosses give no forces; the 100% must come entirely from trash (Windrunner guides: "killing all four bosses alone does not get you to 100%" [src search summary]). In our data bosses are in `bosses` and packs carry `forces`; keep boss forces at 0 and set `forcesRequired` = floor(0.80 x sum(pack.forces)). [code][inf]
- Pull value: a normal pack 6-15 forces; big pull 15-28; Lieutenant/mini-boss pack 15-30 (17-28 in les_uyanisi/yanki); a patrol 5-10. For the typical 400-force dungeon: about 30 packs, mean 13.
- Pack forces must equal the sum of its members' `EnemyDef.forces` (the `pack()` helper does this and throws on unknown ids). Do not hard-code forces unless the enemy def is wrong.
- Optional packs (the dead end) hold 6-8% of total forces so skipping it is viable but costs time. [inf]
- Route planning: provide at least one clear "required" path whose non-optional packs reach `forcesRequired` (verify: kemik 295 total, optional 4 packs, non-optional 239 vs 235 required).

### 3.4 Interrupt, dispel, CC design (data-side)

Our trash uses `EnemyDef` abilities elsewhere (enemies_*.ts), not the dungeon file. Dungeon files decide **who stands where**. Checklist for a pack:

1. Every pack with a caster has at least one more caster within a different pack on the way, so the interrupt rotation matters (2-3 casters per segment; Method lists 2-4 per area).
2. Every dungeon has 2 "kill-first" mobs (healer or shield-caster) in a pack with melee in front: use `front`/`back` rank arrays in `pack()` (front = melee at +z, back = casters at -z).
3. At least 1 "must-not-pull-together" pair (two packs 8+ tiles apart so a careless tank pulls both; WoW: two Forge Loaders, two Rock Smashers).
4. Hazard mobs (death explosions, puddles, fixate): 1 pack with such a mob per boss segment, in a room with space to kite.
5. Dispel target: at least one pack with poison/curse/magic debuff mob per segment.
6. A 'purge' buff target (Territorial Dragonhawk's Bolstering Flames, Zealous Templar): at least one pack.

### 3.5 Patrol and pull-path rules

- Patrol loop: 3-5 tile waypoints; passes through a doorway (so it can be pulled "late"); never loops through a boss arena. Patrol speed is the enemy's normal; do not make patrols the only route to an objective.
- Pull path: leave a straight 3-wide lane from the pack to the next pack so the tank can drag and cleave; place the pack at the room edge not centre when you want a "pull to the wall" (Honor Guards charge; Phalanx Breaker Break Ranks at a wall [src Method]).
- Chain pulls: group the 3 packs of one room within 6 tiles of one another so one big pull can merge them (the kemik "clear pull path" idea). 
- Avoid placing two packs closer than 3 tiles unless `linkedTo` is intended.

### 3.6 Trash events (optional, 1 per dungeon)

Pick from: free N prisoners (Maisara), light 5 stockpiles (Floodgate), find 4 eyes while avoiding patrols (City of Threads), free dragons and mount them (Grim Batol), a minecart escort (Darkflame Cleft), a gauntlet room that kicks you to the entrance when seen (Magisters' Terrace library). Implement with `patrol` + `event_lock` / `kill_lock`, NPCs (`extras.npcs`), `dormant` statue packs, or `extras.transits`.

## 4. Boss design patterns

### 4.1 Evidence

All sources agree on the same shape: **2-4 named mechanics**, one **tank mechanic**, one **raid-wide damage beat**, one **positioning/dodge**, optional **add phase / intermission / soak**. Blizzard's encounter designers say each dungeon boss needs a memorable **hook**, plus occasionally one "weird" mechanic among common ones; lower keys allow looser solutions; telegraphs now standardized; healers do not get interrupt duty; targeting auras appear seconds before damage lands. ### 4.2 Boss template (mechanics budget) [inf, matched to the catalogue]

Each boss gets **exactly**:

1. **One tank mechanic**: heavy hit + stacking DoT/debuff or knockback/bleed (Dailcry Pierce Armor, Dorlita Igneous Hammer, Umbriss Skullsplitter). Needs a telegraph (cast bar or ground cone) and a recovery.
2. **One group-wide damage beat on a timer or energy cap**: at 100 energy do X (E.D.N.A. Earth Shatterer, Anub'zekt Eye, Ki'katal Singularity). 
3. **One positioning mechanic**: dodge circles (Dailcry Earthshattering Spear), soak circles (Braunpyke Sacrificial Pyre), line/cone (Dorlita Lava Cannon), spread (Kroluk), stack (Avanoxx), edge-drop (Emberdawn).
4. **Optional fourth, the hook**: adds (Avanoxx/Kroluk/Skarmorak), an intermission (Aldryr 66%/33%, Rasha'nan 64%, Murrpray 50%), an arena object (candles, vents, rifts, spikes), or a twin boss with shared health.

Phase budget: 0-1 phase transitions. Where there are two phases, trigger on HP (66/33/50%) or energy, and the second phase adds exactly one new object, never replaces all mechanics.

### 4.3 Telegraphs and readability [src seramate; loc]

- Every damaging ground effect has a visible warning (our `HazardDef.warn` seconds, boss script telegraph): 1.5-3 s for circles, 3-5 s for lines/cones (Streetsweeper 3 s, Unbridled Void channel). 
- Floor and effect colour differ: Blizzard teams set a palette per boss so effects stand out from the floor texture (Stonevault note, [loc] tww-midnight.md). So the room's `floor`/`style.floorTint` and the boss's VFX colour must be non-adjacent hues (lava orange floor -> no orange telegraph; use cyan or white).
- Tank buster has a cast bar or a visible wind-up animation (Rak'tul Spiritbreaker, Throngus weapon swap).
- Healer roller coaster: alternate damage beats with recovery windows of 10-20 s (Blizzard: roller coaster). [src]
- Adds spawn from fixed points visible in the arena (eggs, vents, portals), not randomly in the dark.

### 4.4 Arena hazards and geometry

Use `RoomDef.zones` and `hazards`:

| WoW pattern | our data |
|---|---|
| central hole/pit (Rookery) | `zones: [{ kind:'pit', shape:'circle', blocked:true, rect: ... }]` with a `bridge` ring |
| vents (Machinists) | `zones: [{ kind:'vent', rect, hazard:{coef,interval} }]` x4 + boss script picks 3 |
| lava falls/edge (Stonevault) | `kind:'lava', blocked:true` along 2 edges; `dais` platform y 2 |
| rift/void (Eirich) | `kind:'void'` circles at room edges; `fall:'open'` only when the fall is scripted |
| platform fights (Rookery, Murrpray two levels) | `heightAreas` with rim `rail`; ramps via `slopes` |
| periodic debris | `hazards: [{ kind:'debris_fall' | 'lava_burst' | 'icicle_drop' ... , interval, warn, radius, coef }]` |
| dais/throne | `kind:'dais'` y 2 |
| storm rods (Halls of Valor lightning) | `HazardDef.groundedBy` |

Rules: arena has 1 permanent feature + at most 2 temporary hazards; never more than 35% of the floor blocked; spawn points for adds and soak circles keep 4 tiles from the door.

### 4.5 Escalation to the final boss

From the Midnight/TWW last bosses [src]: Eirich (rifts + stacking corruption + pools + frontal = 4 overlapping systems), Restless Heart (arrows used both as hazard and as cure), Rasha'nan (bombs, flight intermission, platform change), Geezle Gigazap (kite sparks into puddles, knockback off an edge), The Darkness (light radius that runs out), Rak'tul (bridge gauntlet), Lothraxion (disguise, kill the right image).

Escalation rules [inf]:

1. The final boss uses 4 mechanics (vs 3), at least one **requires player coordination** (ping a rift, bait to the edge, hand off a bomb).
2. Its mechanics **recombine earlier tools**: a mechanic from boss 1 (adds) plus a mechanic from boss 2 (soak) plus one new object.
3. One **intermission** (movement or add burst), one **enrage-proof soft limit** (stacking DoT or energy cap), not a hard timer.
4. Arena is largest/highest of the dungeon, with a unique floor treatment.
5. Final-boss pre-fight: a mini-boss or gauntlet in the approach (Titan tunnel + Rock Smashers; Zil'jan on the bridge; Kroluk's calls).
6. Post-fight: exit portal, treasure chest (`extras.chests`), a 10-20 s room-wide celebration (lights shift to warm).

### 4.6 Multi-boss rooms (twins)

When two bosses share a room (Fangs, Machinists, Derelict Duo, Muro'jin+Nekraxx, Demolition Duo):
- shared or linked health; killing one buffs the other (Silenced Speaker +75% dmg), so kill within 10 s;
- two tank mechanics (one per boss) and one shared hazard;
- data: two `BossPlacement` entries in the same `roomId` with the same `order` (taskasa, yigitler already do this).

## 5. Theming and storytelling

### 5.1 Environmental storytelling patterns [src]

- The dungeon's story is told in the order you walk it: Stonevault (failed Awakening Machine -> worn-down Earthen -> hidden Eirich), Maisara (free the prisoners -> follow the hex magic -> the monster below), Magisters' Terrace (scholarly academy breached by Void), Windrunner (family garden -> banshee wing -> vault -> grief spirit).
- **Before/after** scenes: Magisters' Terrace has unconscious blood elves rather than dead ones, Windrunner shows haunted relics (harp, bow, maps). Place 1 "story prop group" per room (3-6 props: relic table, bodies, writing desk).
- **Faction fights in the first room** (Xenas): enemies from different factions fighting teaches the villain situation without text. Use two enemy models in the same pack or neighbouring packs facing each other (`center` opposite, `facing` implied by offset).
- **Reveals**: the final arena is visible earlier (through windows, grates, a bridge) so the player has a target.

### 5.2 Lighting moods per room [src/img + inf]

The existing Stonevault/Magisters' Terrace notes give two palettes in [loc] tww-midnight.md (Stonevault: scorched umber, rust brown, molten orange, gold, ember red, ash grey, void violet; Magisters' Terrace: midnight indigo, plum, blood red, amber lantern, arcane cyan, lilac marble, starlight silver, void violet-black).

Design rule: **2 dominant hues + 1 accent + 1 danger colour**, 3 lighting states per dungeon:

| state | rooms | `lightColor` / props `light` | fog (`atmospheres`, `RoomDef.fog`) |
|---|---|---|---|
| calm approach | entrance, first corridors | warm 0xffb060 or cool 0x7090ff, low intensity, flicker true | far fog distance 30-45 m |
| tension | mid halls, patrol rooms | lower intensity, darker ambient, colour pulled to the dungeon accent | near fog 8-12, far 28 |
| set piece / boss | arenas | 2 coloured light sources: environment + danger colour (lava vs gold glyphs; cyan tracery vs amber lanterns) | fog clear (far 40+) in the arena so telegraphs read |

Per room:
- At least 3 `props` with `light` (torch rows, braziers, crystals) in every room larger than 8x8; boss arena at least 6.
- `ambientVfx` (embers, motes, dust, snow, spores) on 40% of rooms; 100% of boss arenas.
- Use `RoomDef.atmosphere` + `DungeonDef.atmospheres` (fog blend) so walking between rooms changes the air gradually; les_uyanisi has 24 atmosphere keys, most other files have none.
- `sky` / `moon` for open-air rooms (Magisters' Terrace dome, Court of Stars night): `openAir: true`, `DungeonTheme.sky` stars.
- Light shafts (`tag: 'lightshaft'`) in cave rooms where the zone has a ceiling opening (Stonevault zone note).

### 5.3 Music and ambience beats

No source for actual WoW music. Implementation pattern [inf]:
- One looping `theme.music` per dungeon; do not switch for corridors.
- `RoomDef.ambience` emitters: 1 per room (drip, forge hammer, wind, whisper), a different `SfxId` per theme zone; boss arenas get a layered emitter (2). Only 3 of 13 files use ambience today (yildiz 10 rooms; others 0). 
- Boss-engage and boss-kill sting come from the boss script, not the dungeon file.

### 5.4 NPC events and roleplay

- Court of Stars (spy hunt) and Maisara (prisoners) show that NPC interactions are the main non-combat element. `extras.npcs` (`DungeonNpcDef`) with `lines` (Turkish), `requires` class/profession gate (Priory priest/paladin orbs, Stonevault anvil: warrior/dwarf/blacksmith).
- Buff stations (one per run per player: `extras.stations`): Arcane Tome (5% haste), Stonevault anvil, Priory orbs, Cinderbrew honey pot, shadecasters. Target: 1-2 per dungeon, one on the main path, one in the optional room.
- Boon pads (`extras.boons`): Magisters' Terrace courtyard energy crystals. Target 1-2.
- Winch drop (`dropProps`): Court-of-Stars style environment weapon, target 0-1.
- Transit carts (`transits`): Stonevault/Darkflame; 0-2 per dungeon.
- Mini-bosses speak a line when their pack wakes (pack `note` is tooling-only; use NPC `lines` or boss scripts).

## 6. Checklist (pass/fail) for one dungeon data file

Apply in order. Each item names the field to check. "Pass" values are targets; deviations need a one-line justification in the file header comment.

**A. Macro**
1. [ ] `bosses` has 3 or 4 encounters; every boss `roomId` is a room with `boss: n` set and `order` unique, or shared by exactly two twins.
2. [ ] Rooms 15-22 (`rooms.length`); at least 4 room footprints are distinct (not all 12x12/4x4).
3. [ ] Graph shape: at least one room with 3 doors (fork/hub) and `doors.length - rooms.length + 1 >= 1` cycle, or two parallel branches that rejoin (not a pure tree except sisli_magara).
4. [ ] Exactly one shortcut: a `kill_lock` door with `opensOn.boss` and width 2, room flagged `skip: true`.

8. [ ] First room has a pack or story prop group (not empty), and `start`/`exit` are inside rooms.
9. [ ] The final boss room is the largest or highest room; its approach is a 2-wide corridor of at least 6 tiles.

**B. Space**
10. [ ] Door widths: arenas 4, connectors 2, grand halls 4-6; no door width 1 except a deliberate pinch.
11. [ ] No two boss arenas share the same `w x h`; arenas >= 12x12.
12. [ ] No room is a 4x4 empty connector without props (merge it into a 2xN corridor or give it a landmark).
13. [ ] At least 3 height levels used (`floorY`, `heightAreas`, `slopes`) and `vertical: true` if any is used; every room has `ceiling` when vertical.
14. [ ] Each room has a landmark visible from its doors (a tall prop, statue, large banner, crystal, brazier cluster).

**C. Trash**
15. [ ] Non-boss packs 22-32 (+/- 5), avg members 3-5, at most 2 packs with >= 7 members, no pack above 8 except a deliberate `big` pull.
16. [ ] Each pack has >= 2 distinct enemy ids (except patrols and mini-bosses); each room's packs mix melee + caster/healer.
17. [ ] 2-3 `patrol` packs; 2-3 `dormant` packs; 1-2 `linkedTo`; 1-2 `big: true`; 3 mini-boss/elite packs.

19. [ ] Every pack inside its room's rect with 2+ tile margin to walls; no two non-linked packs closer than 3 tiles.

**D. Bosses**
21. [ ] Each boss arena has `zones` or `hazards` or `heightAreas` or props that a boss script can use (vents, rifts, pillars). Name the mechanic in a comment.
22. [ ] Boss arena has a unique feature distinct from other arenas (circle zone, dais, pit ring, gallery).
23. [ ] Twin bosses share `roomId` and `order`.
24. [ ] Final boss arena has a distinct `lightColor`, `atmosphere` and at least 6 lit props.

**E. Theme and polish**
25. [ ] Each room has `floor` and `wall` choice consistent with the theme and varied between zones (>= 2 floor styles, >= 2 wall styles per dungeon).
26. [ ] >= 3 lit props in rooms larger than 8x8; `ambientVfx` in >= 40% of rooms.
27. [ ] `atmospheres` has >= 3 states (calm / tension / set piece) and every room with `fog` uses one.
28. [ ] `ambience` emitters in >= 50% of rooms.
29. [ ] Props per room average >= 12 (hand-placed), <= 60 (budget).

## 8. Implementation notes for the cheaper agents

1. Work in tile coordinates; keep `OLD_RECT`/`toNew` frames only if hand-placed props already exist (kemik pattern). Prefer re-authoring in final rects.
2. After any geometry change run `node tools/content-check.mjs <dungeon_id>` (needs Node 22.18+). The stats snippet used for this blueprint is trivial: load `DUNGEONS` from `src/data/dungeons/index.ts` through the same resolver hook as `content-check.mjs`.
3. Keep each pack's `members` and `forces` unless the checklist says to split; moving a pack means changing `roomId` and `center` only.
4. Use `shortcut()` from kemik_mahzeni for kill_lock shortcuts: `{ ...door(a, b, tx, tz, side, width, 'kill_lock'), opensOn: { boss } }`.
5. Do not touch boss scripts in `src/ai/bosses/*`; this blueprint only restructures `src/data/dungeons/*.ts`. Where a recommendation needs a new mechanic (library gauntlet, valves) note it in the file header as TODO for the boss/event module.
6. Order of work per dungeon: rooms and doors -> bosses and packs -> forces -> zones/hazards -> props and lights -> extras -> checklist.
