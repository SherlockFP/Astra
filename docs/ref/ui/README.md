# User reference screenshots (World of Warcraft, modern UI) — the target look

The user (Turkish) shared these as "do it like this". Files that exist: `wow-dungeon-entrance.webp`,
`wow-elvui-hud-actionbars.png`, `wow-details-dps-hps-meter.png`, `user-town-plaza-bugs.webp`.
Two more were shared only in chat (described in detail below).

## 1. wow-elvui-hud-actionbars.png — HUD / unit frames / action bars (ElvUI-style)
- Flat, dark, semi-transparent panels; 1 px dark borders; no ornate frames. Compact.
- Player frame just LEFT of screen centre (slightly below middle): a single wide flat HP bar (teal) with right-aligned
  text "805K | 100%", a row of 4 small buff icons ABOVE it (stack counts in the corner), consumable icons BELOW it
  (potion icons with counts "59", "382").
- Target frame just RIGHT of centre: thin flat bar with centred "100%" (cast/HP) and a row of 6 larger debuff/aura icons
  under it, plus a second row of 4 smaller icons (stack counts).
- Action bars: bottom centre, a tight GRID of square icons (3 rows × 12), no gaps, tiny keybind labels top-right of each
  icon (S2, S3, C4, M5, SG, F1…F5, R, V, Z…), charge/stack counts bottom-right, cooldown darkening; empty slots dark.
- Icons are crisp square ability art with a thin dark border.

## 2. wow-details-dps-hps-meter.png — Details! damage meter
- Two side-by-side meters: "DPS" (left) and "HPS" (right), each 5 rows.
- Each row: spec icon at the left, a full-width horizontal bar in the CLASS colour (purple, blue, yellow-green, orange,

- Below: a "Deaths" mini-list. Header text small and plain.

## 8. wow-great-vault.webp — Great Vault (weekly)
- Full-screen dark parchment window; header "Add items to the Great Vault by completing activities each week. Once per
  week you may select a single reward."
- 3 rows with painted art on the left: "Raids", "Dungeons", "World". Each row has 3 reward cards:
  Raids: Defeat 2 / 4 / 6 season bosses; Dungeons: Complete 1 / 4 / 8 Heroic, Mythic or Timewalking dungeons;
  World: Complete 2 / 4 / 8 world activities.
- Unlocked card: green check, golden glowing reward swirl, item level + source at bottom right in green
  ("318 (Heroic)", "318 (Mythic 20)"), green progress line along the bottom. Locked card: dark, padlock icon,
  progress "0/2", "0/4", "0/8".
- Bottom: "Or" + a "Collect [currency icon] x1" button (take currency instead of an item).

## 9. (chat only) Metin2 market square — player shops ("Pazar")
- A wide paved town square (grey cobblestone) packed with dozens of tiny private-shop stalls: each stall is a small
  wooden box/table on legs with a cloth bundle, a seated or standing seller character beside it (some on horses).
- Above every stall floats a dark semi-transparent rectangular sign with the shop title in small white/yellow text

- Feel: a busy bazaar, the social/economic hub of the server.
