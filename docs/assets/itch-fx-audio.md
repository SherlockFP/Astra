## 1. VFX sprite sheets

All sheets were re-packed into a clean grid. Frames have an integer size, run row-major from the **top-left** cell, and have no empty leading or trailing cells. To play a sheet in three.js (default `flipY = true`), for frame `i`:

```ts
const col = i % cols, row = Math.floor(i / cols);
tex.repeat.set(1 / cols, 1 / rows);
tex.offset.set(col / cols, 1 - (row + 1) / rows);
tex.magFilter = tex.minFilter = THREE.NearestFilter; tex.generateMipmaps = false; // PSX look
```

Use `transparent: true, depthWrite: false` on the sprite material. `blending`: `additive` means the sheet was designed for additive blending; it has also been converted to RGBA, so Normal blending works too. `additive-ok` means it looks good either way. `normal` means use NormalBlending. The `fps` values are suggestions: Super Pixel Effects are authored for 15 fps, while Brackeys flipbooks and predrawn sheets were not timed by their authors.

## 3. Audio: spell and heal impacts (Lentikula) and voices (John Carroll)

No system ffmpeg is installed, so the WAVs were encoded with **Blender's bundled Audaspace/ffmpeg** (`tools/blender/fx_audio/encode_audio.py`). Each file is mono Ogg Vorbis at 48 kHz: 96 kbps for spells and heals, 80 kbps for voices. Leading and trailing silence below -50 dB (relative to peak) was trimmed, keeping a 10 ms pre-roll and a 60 ms tail with short fades, and each file is peak-normalised to -1 dBFS. All 373 files were decoded with `OfflineAudioContext.decodeAudioData` in Chromium without errors; durations match within 3 ms.

Total: **373 files, 5.53 MB**, down from about 113 MB of source WAV.

- `volume` is a GainNode value that brings a file to about -18 dB active RMS, matching the convention in [audio.md](audio.md).
- The orc pack was recorded quietly, so normalisation raised it by +5 to +22 dB. Its noise floor is therefore a little higher; keep orc voices at the suggested volume or lower.
- These files fill the gaps listed in audio.md: human grunts, death cries and the war cry (`voice-warrior-attack:heavy-attack`, `voice-warrior-emote:angry`).
- Mapping suggestions for existing SfxIds: `player_hurt` -> `voice-<class>-hurt`; `player_death` -> `voice-<class>-death`; `war_cry` -> `voice-warrior-attack:heavy-attack`; `fire_impact` / `frost_impact` / `lightning_impact` -> layer `spells:fire-impact`, `spells:ice-impact`, `spells:lightning-impact`; `heal` -> `heals`; orc and goblin `enemy_aggro` -> `voice-orc-emote:angry`; orc `enemy_death` -> `voice-orc-death`.
- Warrior voice goes with Knight and Barbarian. Mage voice goes with Mage (and Cleric if no other voice exists). Orc voice goes with orc, goblin and brute enemies and gruff town NPCs.
