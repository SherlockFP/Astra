# Generated creatures (Blender, procedural, PSX style)

12 rigged + animated dungeon creatures (10 base creatures + 2 slime recolours) that complement the KayKit skeletons and adventurers.
Everything is generated by script, nothing is hand-modelled, so any asset can be rebuilt from scratch.

- Models: `public/assets/models/gen/creatures/<id>.glb` (URL `/assets/models/gen/creatures/<id>.glb`)
- Generators: `tools/blender/creatures/` (`clib.py` geometry/rig/anim/export helpers, `ptex.py` numpy pixel textures, one `c_*.py` per creature, `build_creatures.py` entry point, `render_preview.py` preview sheets)
- Previews: `docs/assets/previews/creatures.png` (contact sheet, Idle frame 0, 3/4 view) and `docs/assets/previews/creatures_poses.png` (one row per creature: Idle / Walk / Run / Attack / Cast / Hit / Death-end)

## Conventions (all assets)

| Topic | Value |
|---|---|
| Units / axes | 1 unit = 1 m, +Y up, creature faces **+Z** (same as KayKit). Origin = ground contact at bottom centre. |
| Rig | One skinned mesh, armature node `Rig`, root bone `root`. Mostly rigid per-part skinning (PSX style); the slime body, wraith robe and wolf torso use gradient weights. |
| Clips | `Idle`, `Walk`, `Run` loop seamlessly. `Attack`, `Attack2`, `Cast`, `Hit` start and end near the rest pose. `Death` ends on a lying/collapsed pose, so play it with `LoopOnce` + `clampWhenFinished = true`. All clips are **in place** (no root motion). Every clip keys every bone, so cross-fading is safe. 30 fps sampling. |
| Texture | One embedded 64x64 PNG atlas per creature (16 px tiles, 4-6 colour ramps with ordered dither), sampler NEAREST. |
| Materials | `*_main` opaque (back-face culled), `*_main2s` double-sided (bat/imp wing membranes), `*_glow` emissive (emissive texture = base texture, `KHR_materials_emissive_strength` 1.6-2.5, made to be picked up by bloom), `*_alpha` alpha-BLEND double-sided (wraith robe/hood/sleeves). roughness 0.9, metallic 0. |
| Vertex colours | `COLOR_0` = baked per-part vertical AO (0.55-1.0 grey) multiplied into base colour. GLTFLoader turns `vertexColors` on automatically. If you replace materials, keep `vertexColors: true` or accept slightly flatter shading. |
| Budget | 228-1016 tris, 40-236 KB per GLB (largest: golem). |

## Rebuilding

```bash
B="/c/Program Files/Blender Foundation/Blender 5.2/blender.exe"
# all creatures (or list ids after the output dir)
"$B" --background --factory-startup --python tools/blender/creatures/build_creatures.py -- "C:/Users/Sher/Desktop/ARPG/public/assets/models/gen/creatures"
# preview sheets (re-imports the GLBs)
"$B" --background --factory-startup --python tools/blender/creatures/render_preview.py -- "C:/Users/Sher/Desktop/ARPG/public/assets/models/gen/creatures" "C:/Users/Sher/Desktop/ARPG/docs/assets/previews/creatures.png" "C:/Users/Sher/Desktop/ARPG/docs/assets/previews/creatures_poses.png"
# verify
node tools/glb-inspect.mjs public/assets/models/gen/creatures --short
```

A full build takes ~6 s and the previews ~1-2 min. `build_creatures.py` also writes `tools/blender/creatures/build_stats.json` (tris, bones, clips and materials per asset).
To add a recolour, follow `c_slime.py` (a palette dict per variant plus an entry in `REGISTRY`).
